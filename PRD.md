# Product Requirements Document (PRD)
**Product Name:** PokéYou
**Platform:** Web Application (Responsive)
**Tech Stack:** Next.js 16 (App Router), React 19, Tailwind CSS v4, Zustand, Framer Motion, Google Gemini API

## 1. Product Overview
PokéYou is a highly interactive, viral personality-matching web application. Users take a short, engaging quiz to determine their "Pokémon Personality." The app leverages AI (Google Gemini) to dynamically generate an authentic-looking Pokémon Trading Card, tailored to their answers, complete with custom stats, move sets, and a comprehensive personality profile. 

The core loop focuses on deep gamification, stunning visual aesthetics, and high social shareability to drive organic growth.

---

## 2. Completed Stages (V1 Release Candidate)

The application has been successfully built up through Phase 6 as a high-fidelity frontend application with localized state management.

### Phase 1: Core Engine & Aesthetics
- **Dynamic Quiz Flow**: 5-step interactive personality quiz.
- **AI Matching Engine**: Uses Gemini to analyze answers and select the perfect Pokémon, factoring in favorite Pokémon preferences.
- **Procedural Card Rendering**: Generates a visually stunning, downloadable trading card using HTML-to-Image.
- **Card Themes**: 15 custom card themes (Classic TCG, GX, VMAX, Rainbow Rare, Retro Game Boy, etc.) with dynamic CSS environments based on Pokémon typing.

### Phase 2: Interactive Viral Features
- **Booster Pack Opening (`/booster`)**: A dramatic, multi-stage animated sequence (shake, tear, flip) that reveals the generated card with confetti for rare pulls.
- **Battle Simulator (`/battle`)**: Users pit their generated card against iconic NPC trainers (Red, Cynthia, etc.) with math-based win probabilities and animated health bars.
- **Trainer Passport (`/passport`)**: A customizable digital trainer ID card.
- **AI Team Builder (`/team`)**: A recommended 6-Pokémon competitive team based on the user's personality traits.
- **Origin Story (`/story`)**: An AI-generated timeline mapping out the user's Pokémon journey.

### Phase 3: Gamification (Local State)
- **Achievements System (`/achievements`)**: Unlockable badges (e.g., "Social Butterfly", "Avid Collector") that grant Experience Points (XP).
- **Daily Rewards (`/rewards`)**: A 5-day streak system tracked via `localStorage` granting XP, mystery themes, and rare Pokémon pulls.
- **League Ranks**: Users progress from *Rookie* to *Pokémon Master* based on earned XP.

### Phase 4: Trainer Dashboard
- **Hub (`/dashboard`)**: A centralized dashboard providing an at-a-glance view of the user's login streak, total XP, achievements, and latest generated card. 

### Phase 5: Monetization Mockup
- **Premium Tier (`/premium`)**: A high-conversion landing page for a $5/month "Pro Trainer" subscription. Showcases features like Unlimited Generations, Shiny Boosts, and Premium Backgrounds.

### Phase 6: Community & Social Mockups
- **Global Leaderboard (`/leaderboard`)**: A ranking page that contextualizes the user's local XP against a mock list of top global trainers.
- **Community Hub (`/community`)**: A gallery feed displaying cards generated by other users to inspire new quiz attempts and theme discoveries.
- **Native Sharing**: One-click sharing to Twitter, WhatsApp, Gmail, or native device share menus.

## 3. What's Next (Roadmap to Production & Beyond)

While the frontend, gamification loops, and AI generation are fully complete, the current application relies on `localStorage` for state management. The next phases focus on converting mockups into live backend infrastructure and launching the product.

### Stage 1: Cloud Infrastructure & Authentication
*Replacing localStorage with a live database.*
1. **Database Setup (Supabase / PostgreSQL)**:
   - Create schemas for `users`, `cards`, `achievements`, and `streaks`.
   - Setup Row Level Security (RLS).
2. **Authentication (NextAuth / Supabase Auth)**:
   - Implement Passwordless login (Google OAuth + Magic Links).
   - Prompt users to authenticate *only* when they want to save their card to the cloud or appear on the global leaderboard.
3. **Data Migration**:
   - Write logic to merge a user's anonymous `localStorage` session (XP, streak, cards) into their cloud profile upon first sign-in.

### Stage 2: Live Community & Monetization
*Connecting the mockups to live APIs.*
1. **Live Leaderboards & Hub**:
   - Wire `/leaderboard` to query the Supabase `users` table, ordered by XP.
   - Wire `/community` to fetch recently generated public cards.
2. **Stripe Integration**:
   - Create Stripe Checkout Sessions for the $5/mo Premium Tier.
   - Implement Stripe Webhooks to upgrade the user's role in Supabase upon successful payment.

### Stage 3: Feature Expansions (V2)
1. **Multiplayer Card Battles**: Expand the Battle Simulator to allow users to generate a shareable "Battle Link" to challenge their friends' cards asynchronously.
2. **Physical Card Printing**: Partner with a print-on-demand API (like Printful or Prodigi) to let users buy a physical, holographic printed version of their custom card.
3. **AR Desk Preview**: Use WebXR to let users see their generated card floating on their physical desk through their phone camera.
